# PRD: 3D 프린팅 제작 및 후처리 중간평가 실기 재시험

| 항목 | 내용 |
|---|---|
| 작성일 | 2026-11-06 |
| 시험일 | 2026-11-12. 1회차 11:00~11:50, 2회차 12:10~13:00 |
| 배포 위치 | GitHub Pages `https://eventia.github.io/3dCad/sau-retest/` + Google Apps Script 웹앱 |

## 1. 목적
- 학번 끝 3자리(A·B·C)로 학생마다 치수가 다른 문제 5개를 한 문제씩 출제한다.
- 답안 PDF는 문제별로 교수 구글 드라이브에 저장하고, 제출 기록은 구글 시트에 남긴다.

## 2. 구성
- **GitHub Pages(공개)**: 화면 표시만 담당한다. `index.html`(포스트잇), `3dCad/sau-retest/`(입장·대기·문제·제출·완료)
- **Apps Script(비공개)**: 시간 판단, 문제 순서, 도면 SVG 생성, 진행 기록, PDF 저장을 담당한다. 문제가 시작 전에 새지 않도록 도면 코드는 공개 저장소에 두지 않는다.

## 3. 기능 요구사항
- R-1 메인 페이지에 "3D 프린팅 제작 및 후처리 중간평가 실기 재시험" 포스트잇을 두고, 클릭하면 재시험 페이지로 간다.
- R-2 이름, 반, 학번(숫자 3자리 이상)을 입력해 입장한다.
- R-3 문제 5개(쉬움 3, 중간 2)를 쉬움 → 쉬움 → 중간 → 중간 → 쉬움 순서로 낸다. 같은 난이도 안의 순서는 학번별로 랜덤이고, 같은 학번은 항상 같은 순서가 나온다.
- R-4 치수 A·B·C = 학번 끝 3자리 × 10mm (0은 100mm)
- R-5 시작 전에는 카운트다운만 보여 주고, 시작 시각이 되면 첫 문제가 자동으로 나온다. 시각 판단은 서버 기준이다.
- R-6 화면에 종료 시각과 제출 마감 시각, 남은 시간을 항상 표시한다.
- R-7 종료 후 2분(유예)까지 제출을 허용하고 시트에 표시한다. 그 뒤에는 서버가 제출을 거부한다.
- R-8 문제마다 PDF(10MB 이하)를 1회만 제출할 수 있다.
- R-9 [다음 문제]로 넘어가면 이전 문제로 돌아갈 수 없다. 제출하지 않고 넘어가는 것은 허용하되 확인 창을 띄운다.
- R-10 새로고침하거나 다시 접속하면 현재 문제부터 이어서 본다. 다른 기기에서 같은 학번으로 접속하면 막는다(감독관이 시트에서 해제 가능).
- R-11 회차는 접속 시각으로 정하며, 한 회차에 응시한 학번은 다른 회차에 응시할 수 없다.
- R-12 제출 기록: 제출 시각, 회차, 학번, 이름, 반, 순번, 문제 ID, 난이도, A·B·C, 파일명, 크기, 유예 제출 여부, 드라이브 링크

## 4. 인수 기준
- [ ] 메인 포스트잇 → 재시험 페이지로 이동한다
- [ ] 시작 전 입장 시 카운트다운이 보이고, 시작 시각에 자동으로 문제 1이 나온다
- [ ] 문제 1, 2는 쉬움, 3, 4는 중간, 5는 쉬움이다
- [ ] PDF 제출 후 드라이브(`학번_이름/Q{n}_...pdf`)와 `제출` 시트에 기록된다
- [ ] 같은 문제를 다시 제출할 수 없고, 넘어간 뒤 이전 문제에 제출할 수 없다
- [ ] 종료 후 2분 안의 제출은 Y로 표시되고, 그 뒤 제출은 거부된다
- [ ] 다른 브라우저에서 같은 학번으로 접속하면 거부된다
