# PRD: 신안산대학교 중간고사 실기 — 학번별 문제 페이지

| 항목 | 내용 |
|---|---|
| 작성일 | 2026-10-28 |
| 배포 위치 | GitHub Pages — `https://eventia.github.io/3dCad/sau-midexam/` (기존 저장소에 추가) |
| 상태 | 2단계 완료 — 실제 도면 2개(문제 1, 2) 적용 |

## 1. 배경 및 목적
- 실기 시험에서 학생마다 서로 다른 치수의 문제를 주어 답안 베끼기를 방지한다.
- 학번을 입력하면 자동으로 개인별 치수(A, B, C)가 계산된 도면 문제가 표시된다.
- 서버 없이 정적 페이지(HTML/CSS/JS)로 GitHub Pages에서 운영한다.

## 2. 사용자
- **학생**: 사이트 접속 → 이름·반·학번 입력 → 자신의 문제 확인 → 작도
- **교수자**: 도면 이미지와 문제 문구를 준비하고 저장소에 반영

## 3. 사용자 흐름
1. `eventia.github.io` 접속
2. 메인 메뉴의 **"3D CAD"** 클릭 → `/3dCad/` 이동
3. **"신안산대학교 중간고사 실기"** 클릭 → `/3dCad/sau-midexam/` 이동
4. 이름, 반, 학번 입력 후 **[문제 보기]** 클릭
5. 개인별 A, B, C 값이 적용된 문제 화면 표시
6. 필요 시 **[화면 캡처]** 또는 **[다시 입력]**

## 4. 기능 요구사항

### 4.1 메뉴 페이지
- F-1: 루트 `index.html`은 기존 내용을 없애고 "3D CAD" 링크 카드만 둔다. `3dCad/index.html`에 "신안산대학교 중간고사 실기" 링크 카드와 [← 처음으로] 링크를 둔다. 두 페이지는 공통 스타일(`site.css`)로 심플·모던하게 구성하고 다크 모드를 지원한다

### 4.2 입력 폼
- F-2: 이름 입력 (필수, 공백 불가, 한글로 입력 안내)
- F-2a: 반 입력 (필수, 공백 불가, 형식 제한 없음)
- F-3: 학번 입력 (필수, 숫자만, 최소 3자리, 숫자만 입력 안내)
- F-4: 검증 실패 시 입력란 아래 오류 메시지 표시, 문제 화면으로 넘어가지 않음

### 4.3 치수 계산 규칙
- F-5: 학번 **끝 3자리**를 순서대로 사용
  - 뒤에서 3번째 자리 → A, 뒤에서 2번째 → B, 마지막 자리 → C
- F-6: 길이(mm) = 자릿수 × 10
- F-7: 자릿수가 **0이면 10으로 간주** → 100mm
- 결과 범위: 10 ~ 100mm

| 학번 | 끝 3자리 | A | B | C |
|---|---|---|---|---|
| 2024123456 | 4, 5, 6 | 40 | 50 | 60 |
| 2024123406 | 4, 0, 6 | 40 | 100 | 60 |
| 2024123000 | 0, 0, 0 | 100 | 100 | 100 |
| 2024123191 | 1, 9, 1 | 10 | 90 | 10 |

### 4.4 문제 화면
- F-8: 상단에 시험명("신안산대학교 2026년 중간고사 실기"), 이름, 반, 학번 순서로 표시
- F-9: A, B, C 값을 표로 표시
- F-10: 문제 지시문 표시 (문구는 교수자가 제공, 미정 시 임시 문구)
- F-11: 문제 1, 문제 2 도면을 한 화면에 위아래로 표시하고, 각 도면의 A, B, C 글자 위에 값을 겹쳐 표시 (4.5 참고). 두 문제는 같은 A, B, C 값을 사용 (문제 1은 A, B만 사용)
- F-11a: 문제 2 아래, 버튼 위에 답안 제출 안내 표시 — 문제 캡처와 Onshape 최종 Drawing 캡처를 답지(구글 설문지 https://forms.gle/mxpmkRoTyCpYQESXA, 새 탭)에 제출. 화면 캡처 이미지에서는 제외
- F-12: [다시 입력] 버튼 — 입력 폼으로 복귀
- F-13: [화면 캡처] 버튼 — 문제 화면(버튼 제외)을 PNG 이미지로 저장. 파일명 `중간고사_반_학번_이름.png`. html2canvas(cdnjs) 사용

### 4.5 도면 오버레이
- F-14: 도면은 PNG 이미지(`3dCad/images/`)로 제공. 도면 속 A, B, C 글자(밑줄 포함)를 흰 바탕 숫자로 덮어 표시
- F-15: 좌표는 원본 이미지의 **픽셀 좌표(글자 중심)** 로 설정하고, 화면에서는 이미지 대비 %로 변환해 화면 크기와 무관하게 위치 유지. 숫자 크기도 이미지 폭에 비례
- F-16: 세로 치수선용 회전(예: -90°) 지원
- F-17: 문제 목록(제목, 이미지 경로·크기, 숫자 크기, A/B/C 좌표·회전)은 `exam.js`의 `problems` 배열 한 곳에서 관리 → 문제 추가·교체 시 이미지와 이 배열만 수정

## 5. 도면 준비 계획 (단계적 진행)
- **1단계 (완료)**: 임시 도면으로 사이트 전체 동작 확인
- **2단계 (완료)**: 실제 도면 `work01.png`(팔각 판재, A·B), `work02.png`(브래킷, A·B·C) 적용, 글자 위치를 픽셀 단위로 측정해 좌표 설정
- 참고: 문제 2는 오른쪽 측면도 치수(20, 9, 5 등)가 고정이라 A, B, C 값에 따라 형상 비율이 실제와 달라질 수 있음

## 6. 비기능 요구사항
- 정적 파일만 사용 (빌드 도구·외부 서버 없음)
- PC·모바일 브라우저에서 정상 표시 (반응형)
- 한국어 UI
- 코드: 주석 한국어, 변수명 snake_case

## 7. 파일 구성

```
eventia.github.io/
├─ index.html               ← 메인: "3D CAD" 링크
├─ site.css                 ← 메뉴 페이지 공통 스타일
└─ 3dCad/
   ├─ index.html            ← 3D CAD 메뉴: 시험 링크
   ├─ PRD.md                ← 이 문서
   ├─ images/
   │  ├─ work01.png         ← 문제 1 도면
   │  └─ work02.png         ← 문제 2 도면

      ├─ index.html         ← 입력 폼 + 문제 화면
      ├─ style.css          ← 화면 스타일

```
